## 当前实现摘要

- 仅面向 Windows 11；主项目与测试目标为 `net11.0-windows10.0.22621.0`，应用版本仍为 `0.2.0`。
- WPF 主界面，WinForms 仅用于托盘；`AppServices` 手动装配存储，无 DI 框架、无运行期插件。
- 播放源与歌词源独立：QQ / 网易云 / Generic 播放策略已存在；自动歌词源仍是 **QQ → 网易云 → LRCLIB 串行回退**，尚未跨源统一决策。
- 当前优先稳定 QQ 主流程。网易云播放器策略保留，但暂停新增适配与完整实机验收；这不影响网易云歌词源作为兜底。
- 已有卡片悬停选词入口、立即打开的加载态选择器、取消/重搜、跨歌失效保护及置顶窗口。
- 手动列表始终过滤异歌；“显示其他歌手的同名版本”只放宽歌手条件，不再显示全部搜索结果。
- 手选结果优先于同歌自动请求，成功后写入候选专用缓存和选择记忆，支持后续离线复用。

2026-11-13，使用 .NET SDK `11.0.100`：

| 项目 | 结果与边界 |
| --- | --- |

| 隔离镜像回归 | **186/186 通过，0 失败、0 跳过**；业务、测试和 XAML 源保持一致，仅将 `LogService.cs` 替换为无 IO 的 AppLog 边界 |
| 日志覆盖 | 真实日志初始化、目录清理、sink 与 Flush **未由上述镜像验证**；验证脚本与产物为本地资料，不随仓库分发 |
| 框架依赖发布 | 已更新仓库外的 `../dist/release`；发布 DLL 与 Release 构建哈希一致，.NET / Windows Desktop 需求为 `11.0.0`，x64 SQLite 原生库存在 |
| 未验证 | 本轮未做实网歌词请求，也未自动启动或操控播放器；真实按钮点击、跨进程穿透、DPI/多屏、休眠恢复仍需人工验收 |

框架依赖版发布命令（在仓库根执行）：

```powershell
dotnet publish Stanza/Stanza.csproj -c Release --self-contained false -o ../dist/release
```

本机发布固定使用 `../dist/release`，不要为每次修复另建发布目录。覆盖前由用户退出正在运行的 Stanza，不强制结束进程。旧 ZIP、自包含目录与安装包不因这条命令自动更新。
