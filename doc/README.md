## 当前实现摘要

- 仅面向 Windows 11；主项目与测试目标为 `net10.0-windows10.0.22621.0`（.NET 10 LTS）；应用版本以 `Stanza/Stanza.csproj` 的 `<Version>` 为准，`global.json` 限定稳定版 10.0 SDK。
- WPF 主界面，WinForms 仅用于托盘；`AppServices` 手动装配存储，无 DI 框架、无运行期插件。
- 播放源与歌词源独立：QQ / 网易云 / Generic 播放策略已存在；QQ、网易云、LRCLIB 并行搜索候选，自动与手动共用 Lyricify 基线排序；统一置信判断后再串行按候选取词。
- 同平台偏好只影响证据接近的同录音候选；不同版本或歌手不能靠来源放行，证据不足提示手选。自动缓存携带查询指纹和算法版本。
- 当前优先稳定 QQ 主流程。网易云播放器策略保留，但暂停新增适配与完整实机验收；这不影响网易云歌词源作为兜底。
- 已有卡片悬停选词入口、立即打开的加载态选择器、取消/重搜、跨歌失效保护及置顶窗口。
- 手动列表始终过滤异歌；“显示其他歌手的同名版本”只放宽歌手条件，不再显示全部搜索结果。
- 手选结果优先于同歌自动请求，成功后写入候选专用缓存和选择记忆，支持后续离线复用；失败或取消且当前没有歌词时，恢复同曲自动加载。
- 设置、数据库和日志统一使用 `AppDataPaths`；启动前通过 `STANZA_DATA_DIR` 指定目录，Scoop 可指向 `persist/stanza/data`。未指定时保留 AppData 默认值；外部目录不会自动导入旧 AppData 数据。
- 全屏隐藏按卡片所在显示器的完整覆盖判断，排除开始菜单、搜索等系统宿主；显示入口共用隐藏条件，调整位置模式也能在退出全屏后恢复。
- 多屏任务栏定位绑定目标显示器；开始菜单使任务栏暂时不被枚举时保留位置，同屏任务栏重建后继续沿用，仅目标显示器断开后回退主任务栏。应用清单声明 `PerMonitorV2`，统一读取物理像素。
- GitHub 发布工作流为 `v*` 标签触发：版本校验、构建、测试、ZIP/EXE 与各自 SHA256、创建 Release。`v0.3.0` 的自包含 ZIP 已完成云端发布；`0.3.1` 开始准备带/不带运行时的四种包。Gitee 附件同步与独立 Scoop bucket 更新不在应用工作流中。

框架依赖版发布命令（在仓库根执行）：

```powershell
dotnet publish Stanza/Stanza.csproj -c Release --self-contained false -o ../dist/release
```

本机发布固定使用 `../dist/release`，不要为每次修复另建发布目录。覆盖前由用户退出正在运行的 Stanza，不强制结束进程。旧 ZIP、自包含目录与安装包不因这条命令自动更新。
